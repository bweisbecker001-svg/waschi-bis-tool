# Waschi.fun – WoW Mythic+ BiS Dashboard Webversion

Diese Fassung ersetzt den lokalen Windows/Python-Helfer durch eine serverseitige Web-API.

## Enthalten
- `index.html` – Dashboard-Oberfläche
- `api/index.py` – Raider.IO-, Blizzard-, KeystoneLoot- und Medien-API
- `requirements.txt` – Python-Abhängigkeiten
- `vercel.json` – Vercel-Routen
- `Dockerfile` – alternative Installation auf einem eigenen Server/VPS
- `.env.example` – benötigte Blizzard-Umgebungsvariablen
