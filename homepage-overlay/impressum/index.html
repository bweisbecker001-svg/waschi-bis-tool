Datenschutz, Cookies & lokale Speicherung

Waschi.fun verwendet derzeit keine eigenen Analyse- oder Werbe-Cookies. Für einzelne Funktionen werden jedoch Informationen lokal im Browser gespeichert. Dazu gehören insbesondere die gewählte Sprache, die persönliche Einwilligungsentscheidung für externe Inhalte sowie – im BiS-Tool – die vom jeweiligen Nutzer gespeicherten Charakter-Favoriten. Diese Daten bleiben grundsätzlich im verwendeten Browser bzw. Browserprofil und werden nicht als gemeinsame Favoritenliste auf Waschi.fun gespeichert.

Die Website wird über Vercel bereitgestellt. Beim Aufruf der Website werden technisch notwendige Verbindungsdaten verarbeitet, damit die Seite ausgeliefert werden kann.

Auf Waschi.fun können externe Inhalte von Twitch und YouTube eingebunden werden. Diese Inhalte werden erst geladen, nachdem der Besucher der Kategorie „Externe Medien“ zugestimmt hat. Beim Laden können Verbindungen zu den jeweiligen Anbietern hergestellt, technische Nutzungsdaten übertragen und dort Cookies oder vergleichbare Technologien eingesetzt werden.

Wird die Zustimmung abgelehnt, bleiben die externen Player blockiert; die übrigen Bereiche von Waschi.fun können weiterhin genutzt werden. Die Entscheidung kann jederzeit über im Seitenfuß geändert werden.

Das Speichern der Einwilligungsentscheidung ist erforderlich, damit die Website die gewählte Datenschutzeinstellung bei weiteren Seitenaufrufen berücksichtigen kann.
